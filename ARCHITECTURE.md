## 2. 组件详解

### 2.1 Kubernetes集群

**架构选择：3 Master + 3 Worker**

```
为什么选择3 Master：
1. etcd奇数节点（3节点容忍1节点故障）
2. API Server负载均衡
3. 控制平面高可用

为什么选择3 Worker：
1. Pod调度有冗余
2. 节点故障不影响服务
3. 资源足够运行示例应用
```

**关键组件版本：**
- Kubernetes: v1.28.x
- containerd: v1.7.x
- Calico: v3.26.x
- CoreDNS: v1.10.x

### 2.2 CI/CD流水线

```
代码提交流程：

Developer → GitLab → Webhook触发 → Jenkins Pipeline
                                      │
                                      ├── 拉取代码
                                      ├── 单元测试
                                      ├── 代码扫描 (SonarQube)
                                      ├── 镜像构建 (Docker)
                                      ├── 安全扫描 (Trivy)
                                      ├── 推送镜像 (Harbor)
                                      └── 部署到K8s (kubectl apply)
```

**组件职责：**
- **GitLab**: 代码仓库，版本管理
- **Jenkins**: CI/CD引擎，Pipeline执行
- **Harbor**: 镜像仓库，镜像版本管理
- **Trivy**: 容器镜像安全扫描

## 3. 数据流

### 3.1 部署流程

```
完整部署流程：

1. 基础环境初始化 (Ansible批量)
   └── 主机名、SSH、NTP、内核参数、Docker/containerd

2. K8s集群部署 (kubeadm)
   ├── Master初始化
   ├── Worker加入
   ├── Calico网络
   └── 验证集群

3. 存储层配置
   ├── NFS Server
   ├── NFS Provisioner
   └── StorageClass

4. CI/CD部署
   ├── GitLab
   ├── Jenkins
   ├── Harbor
   └── Pipeline配置

5. 监控日志部署
   ├── Prometheus + Grafana
   ├── ELK Stack
   └── 告警配置

6. 应用部署
   ├── 示例应用
   ├── HPA配置
   └── 故障转移测试

7. 高可用配置
   ├── Keepalived
   ├── Nginx LB
   └── 数据库主从

8. 安全加固
   ├── SSL证书
   ├── 防火墙
   └── 容器安全
```

用户 → VIP(192.168.1.100) → Nginx LB

## 4. 容灾设计

### 4.1 故障场景

| 故障场景 | 影响 | 恢复方案 |
|----------|------|----------|
| 单Worker节点故障 | Pod迁移 | K8s自动重新调度 |
| 单Master节点故障 | API Server冗余 | 其他Master接管 |
| etcd单节点故障 | 集群正常 | 3节点容忍1故障 |
| NFS Server故障 | 存储不可用 | Keepalived VIP漂移 |
| MySQL Master故障 | 写入中断 | Slave自动提升 |
| Redis Sentinel故障 | 哨兵冗余 | 3节点容忍1故障 |
| Nginx LB故障 | 流量中断 | Keepalived切换 |

### 4.2 备份策略

```
备份内容：

1. etcd快照: 每6小时
   └── etcdctl snapshot save

2. K8s资源: 每天
   └── kubectl get all --all-namespaces -o yaml

3. 配置文件: 每天
   └── Ansible同步备份

4. 数据库: 每天全量 + binlog增量
   └── xtrabackup + binlog

5. Harbor镜像: 每周
   └── Harbor Replication
```
